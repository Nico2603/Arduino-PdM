# Bibliotecas requeridas para ESP32_Sensor v2.0.0

# Incluidas con ESP32 (no requieren instalación manual)
- WiFi
- Wire
- SPIFFS (Sistema de archivos)

# CAMBIO: Reemplazar HTTPClient con PubSubClient para MQTT
# Instalar desde el Gestor de Bibliotecas de Arduino IDE
- PubSubClient (versión 2.8.0 o superior) - NUEVO: Para MQTT
- Adafruit MPU6050 (versión 2.0.0 o superior)
- Adafruit Unified Sensor (versión 1.1.4 o superior)
- Adafruit BusIO (automáticamente instalado como dependencia)
- ArduinoJson (versión 6.19.4 o superior)

# Configuración de la placa
- ESP32 Dev Module
- CPU Frequency: 240MHz
- Flash Frequency: 80MHz
- Flash Mode: QIO
- Flash Size: 4MB
- Partition Scheme: Default 4MB with spiffs
- Upload Speed: 921600
- Core Debug Level: None

# Notas de compatibilidad
- Arduino IDE 1.8.19 o superior / Arduino IDE 2.x
- ESP32 Arduino Core v2.0.2+ (IDF 4.x) o v3.x (IDF 5.x)
- El código es compatible con ambas versiones mediante compilación condicional

# Versiones de ESP32 Core soportadas:
- v2.0.2 - v2.0.17 (IDF 4.x)
- v3.0.0+ (IDF 5.x)
